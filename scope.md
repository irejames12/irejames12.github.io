# Project 01: Personal Introduction Webpage

## Project Purpose

The purpose of this project is to create a simple personal introduction webpage for CMPA 3301. It will help classmates and the instructor learn about my background, what I am studying, and my interests while showing that I understand basic HTML structure.

## Description

I will build a single-page website called `index.html` using semantic HTML. The page will introduce me, explain that I completed my Computer Information Systems degree at Rochester Community and Technical College and am now earning my bachelor's degree in Computer Applications online at Texas Tech University, and describe my goals for this course and career. It will also include a list of my interests and a link to my GitHub profile. I will focus on making the content clear and organized rather than adding design features.

## Desired Results

1. Create an `index.html` file that opens correctly in a web browser.
2. Include a browser-tab title, my name in an `h1`, a major or professional-interest `h2`, and at least two paragraphs about my coursework and career goals.
3. Include a bulleted list with at least three hobbies or interests and a working hyperlink to [my GitHub profile](https://github.com/irejames12).
4. Use the required HTML elements correctly with clear indentation and readable content.
5. Package `scope.md` and `index.html` together in one ZIP file for the assignment.

## Exclusions

- No CSS styling, custom colors, fonts, or page layouts for this version.
- No JavaScript, interactive features, or external frameworks.
- No images, extra pages, or complicated navigation.
- No attempt to turn this into a complete professional portfolio yet; this is only a personal introduction page.

## Project Priorities and Acceptance

The main priority is a working, clearly structured HTML page that matches this scope. I will check the page in a browser, confirm the GitHub link works, and make sure both correctly named files are in the ZIP before I submit it.
