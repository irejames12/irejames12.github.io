## About This Project

This is my personal introduction website that I created for my CMPA 3301 course at Texas Tech University. The purpose of this website is to introduce myself, share my educational background, and talk about my interests and career goals in technology.

- style.css - Controls the design of my webpage.
- README.md - Explains what my project is about.
