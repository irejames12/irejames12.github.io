# Exercise 06 - The Mini Change Request

**Project Name:** Personal Introduction Website - Ireoluwa James

**Requested By:** Course Instructor

## Proposed Change

The proposed change is to add an embedded Google Map showing Plano, Texas, on my personal introduction website. The map would be placed in a new section of the webpage so visitors can see where I'm from without having to leave the website.

## Reasons for the Change

The instructor requested this feature to make the website more personal and interactive. Since the purpose of my website is to introduce myself, adding a map would give visitors a little more information about my background. It would also allow me to practice adding an outside feature to an existing HTML project.

## How This Change Will Add Value

I think adding the Google Map would improve my website by making it more interesting and giving visitors a better understanding of where I'm from. It would also help me build my HTML skills and learn how to include features from other websites. This could be considered scope discovery because the change adds value to the original project.

## How This Change Will Affect the Constraints

- **Time:** I estimate that adding the map would take around 30 minutes to an hour. I would need to get the Google Maps embed code, add it to my HTML file, and test it to make sure it works.

- **Quality:** The map could improve the quality of my website by making it more interactive. However, I would need to make sure it displays correctly on different screen sizes and doesn't affect the layout.

- **Budget:** I don't expect this change to cost anything because I can use a standard Google Maps embed for free. The main resource needed would be my time.

## Final Recommendation

I would approve this change because it adds value to my website without requiring much extra time or money. As long as the map works correctly and doesn't interfere with the rest of the webpage, I think it would be a good addition to the project.
